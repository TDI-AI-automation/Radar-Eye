# Incident Lifecycle

## Purpose

Define the lifecycle of all incidents generated by the Radar Eye system.

---

# States

## NEW

Description:
Incident has been created by the system.

Entry Conditions:
- Threat Engine generates a threat requiring an incident.

Exit Conditions:
- Incident becomes ACTIVE.

---

## ACTIVE

Description:
Threat condition is currently present.

Entry Conditions:
- Incident created.

Exit Conditions:
- Operator acknowledges incident.
- Threat condition disappears.

---

## ACKNOWLEDGED

Description:
Operator has reviewed the incident.

Entry Conditions:
- Operator acknowledges incident.

Exit Conditions:
- Threat condition resolved.
- Operator marks resolved.

---

## RESOLVED

Description:
Threat condition no longer exists.

Entry Conditions:
- Threat disappears.
- Operator closes incident.

Exit Conditions:
- Retention period expires.

---

## ARCHIVED

Description:
Historical incident retained for audit and investigation.

Entry Conditions:
- Incident retention workflow executed.

Exit Conditions:
- Record deletion policy triggered.

---

# State Transitions

NEW
↓
ACTIVE
↓
ACKNOWLEDGED
↓
RESOLVED
↓
ARCHIVED

---

# Ownership

System:
- NEW
- ACTIVE

Operator:
- ACKNOWLEDGED
- RESOLVED

System Retention Service:
- ARCHIVED

---

# Related Artifacts

Each incident may contain:

- Incident ID
- Camera ID
- Timestamp
- Threat Level
- Snapshot
- Event Clip
- Threat Metadata
- Operator Notes
