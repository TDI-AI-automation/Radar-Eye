# Camera Calibration Specification

## Purpose

Convert image coordinates into real-world ground-plane distances.

---

# Calibration Method

Ground Plane Projection

---

# Installation Workflow

1. Open calibration wizard
2. Select reference points
3. Enter real-world measurements
4. Generate homography
5. Save calibration

---

# Stored Data

- Camera ID
- Homography Matrix
- Reference Points
- Calibration Timestamp
- Operator

---

# Distance Outputs

- Estimated Distance (meters)
- Zone Classification

---

# Recalibration Workflow

Operator self-service recalibration

No engineer required

---

# Validation

Measure known distances:

- 10m
- 20m
- 50m

Calculate error.
